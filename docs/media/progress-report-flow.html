How a progress report stays current

Three inputs feed the report: the plan file or tasks.md with its checkboxes, events from the Claude Code or Codex hooks, and the lane, blocker, decision and note facts you record. progress refresh projects them deterministically into a live browser view, a Markdown export and a one-line status. No agent is kept running to maintain it. Without the hooks, tasks are still tracked but model, effort, context and child agents stay unknown, and the report never writes the plan.
