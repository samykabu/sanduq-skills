A planning-majlis run

Full mode. The skill seats five core roles plus the optional roles you confirm, gathers verified facts, runs specialist tracks in parallel, then has isolated critics score them. Everything folds into one decision record. Each re-score round has the critics score the current record, then gate.py runs: it passes only when every seated role scores 9/10 or more, the record has no OPEN rows, and the roster and tables are valid. On a fail, a drill on the open rows writes the next record version and the next round starts; after six rounds without a pass the run stops and reports the unresolved blockers. On a pass, writers produce the specs from the record, a consistency pass fixes contradictions and runs the gate again, and the hand-off lists the owner decisions with their defaults. Feature mode runs one design track instead of several.
